# Abstract Playbook

## Role

Summarize the problem, limitation, method, evaluation, and result boundary in one compact paragraph unless the venue allows structured abstracts.

## Required Moves

1. State the task and practical motivation.
2. Name the specific unresolved technical issue.
3. Introduce the method with one concise mechanism statement.
4. State evaluation setting and metrics if supplied.
5. Report only verified results.
6. End with bounded significance.

## Checks

- No unsupported performance claims.
- No citation unless venue requires it.
- No claims broader than the experiments.
