# Introduction Playbook

## Role

Move from application importance to a narrow, evidence-supported gap and a controlled method preview.

## Paragraph Roles

1. Application/task importance.
2. Technical challenge and practical failure mode.
3. Prior work families and progress.
4. Missing intersection or unresolved limitation.
5. Proposed method summary.
6. Contributions.

## Style Rules

- Start with the task, not the architecture.
- Use citations early enough to anchor prior progress.
- Treat InvTrack and existing tracking work as novelty boundaries.
- Make each contribution testable.

## Checks

- No `first` claim without direct evidence.
- Each limitation must be explicit or labeled as an inference.
- The final gap must name setting, mechanism, and testable consequence.
