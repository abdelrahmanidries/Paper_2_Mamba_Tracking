# Related Work Playbook

## Role

Synthesize prior methods by functional family and position the current work without exaggerating novelty.

## Recommended Subsections

1. Template-search tracking.
2. Mamba/state-space tracking.
3. Degradation-robust tracking.
4. Restoration-oriented Mamba or image restoration.
5. Position of the present work.

## Required Moves

- Define each method family.
- Acknowledge what prior methods solve.
- State the precise remaining limitation with evidence.
- Use `not reported` when a property is absent from the supplied paper evidence.

## Checks

- No chronological listing without synthesis.
- No unsupported negative claims.
- No citation-free paragraph unless it is a synthesis bridge.
