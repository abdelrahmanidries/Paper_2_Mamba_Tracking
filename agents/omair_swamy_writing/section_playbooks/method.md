# Method Playbook

## Role

Explain the proposed method as a sequence of motivated modules, preserving equations and symbols exactly unless the user requests derivation editing.

## Paragraph Roles

1. Overview and design objective.
2. Input/output notation.
3. Module descriptions in execution order.
4. Losses, training objective, or inference rule.
5. Complexity or implementation details if supplied.

## Checks

- Equations, dimensions, and hyperparameters are immutable in rewrite mode.
- Do not add architectural components not present in the evidence.
- Tie each module to a stated problem.
