# Results Playbook

## Role

Report findings accurately, compare against baselines, and avoid overstating small or mixed gains.

## Paragraph Roles

1. Main quantitative result.
2. Condition-specific behavior.
3. Ablation or component effect.
4. Failure modes.
5. Efficiency trade-off if measured.

## Checks

- Every number must trace to a table or experiment file.
- Mixed results must be reported as mixed.
- Avoid causal claims unless ablations support them.
