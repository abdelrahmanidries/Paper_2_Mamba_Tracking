# Experiments Playbook

## Role

Make the evaluation protocol reproducible and aligned with the paper claims.

## Paragraph Roles

1. Datasets and splits.
2. Baselines.
3. Metrics.
4. Implementation details.
5. Degradation protocol or ablations when relevant.

## Checks

- Dataset names, sequence counts, and metrics must match evidence.
- Do not imply statistical significance unless tested.
- Separate protocol from results.
