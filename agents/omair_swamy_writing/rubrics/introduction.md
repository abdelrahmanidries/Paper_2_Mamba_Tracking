# Introduction Rubric

Score each item from 0 to 2.

| Criterion | 0 | 1 | 2 |
|---|---|---|---|
| Application opening | Architecture-first | Task mentioned | Concrete task pressure first |
| Challenge narrowing | Vague | Partly specific | Specific technical obstacle |
| Prior work synthesis | List only | Some grouping | Method-family synthesis |
| Gap precision | Unsupported novelty | Broad gap | Narrow testable gap |
| Method preview | Missing or too detailed | Present but loose | Controlled and bounded |
| Contributions | Vague | Partly testable | Concrete and auditable |
| Citation discipline | Weak | Adequate | Strong and traceable |

Recommended minimum for release: 12/14.
